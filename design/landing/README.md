# GoodBuild landing mockups

Two static mockups, each one self-contained HTML file (Tailwind CDN + Google Fonts). Open them straight in a browser.

| | A — dark "Editeaze" | B — light "neuro-tech bento" |
|---|---|---|
| File | `mockup-a.html` | `mockup-b.html` |
| Screenshots | `mockup-a-hero.png` (1440×900), `mockup-a-full.png` | `mockup-b-hero.png`, `mockup-b-full.png` |
| Background | `#121212` | `#F5F5F5`, cards `#FFFFFF` |
| Primary | royal blue `#1D35FF` | galactic violet `#592E81` |
| Pop | tangerine `#FF6800` (deploy card, wave glow, wallet dot) | bubblegum pink `#FF85D9` (chart, CTA dot) |
| Display font | Anton, ALL CAPS, line-height .86 | Unbounded 700–800, ALL CAPS, tracking -0.03em |
| Body font | Inter 400/500/600 | Inter 400/500/600 |
| Radii | panels 22px, CTA band 28px, buttons/chips full pill | cards 24px, chips/buttons full pill |
| Surfaces | glass: `rgba(22,22,26,.62)` + 22px backdrop blur + 1px white/9% border; ghost pills with a 1px white/28% border | no borders; shadow `0 1px 2px rgba(17,17,17,.03), 0 18px 50px -24px rgba(89,46,129,.18)` |
| Motion | canvas sine wave drifts (one cycle about 16s), deploy card floats over 5s | line graph draws in over 2.4s, hero render bobs over 6s, the chart's end dot pulses |

Assets (`assets/`): `logo.svg` (G mark, recoloured inline in each page), `hero-b.jpg` (chrome/violet render), `chrome-cube.jpg` (audited-template cube). Both JPGs were AI-generated for this project.
