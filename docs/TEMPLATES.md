# Landing-page templates

The template gallery on the landing page (`#templates`) lists 26 page designs. Each shows a real screenshot of the page and builds it with one click. Decision: [D60](DECISIONS.md).

Generated by `pnpm tsx scripts/templates-doc.ts` from `src/config/page-template-data/`. Don't edit the table by hand.

## How it works
- **One spec per template** (`src/config/page-templates.ts`): palette, type, top bar and ordered sections with their copy, plus what a dApp does on-chain.
- **Thumbnail:** `pnpm tsx scripts/render-templates.tsx` renders each spec to HTML and screenshots it with headless Google Chrome into `public/templates/<id>.png` (960 by 600). So the picture is a real render of the same spec the build uses. Re-run it after changing a spec.
- **One click:** the gallery sends a short request ("Build the Flowdesk template: ...") with the template id through the normal send gate (signed out: sign in first, then it is sent once). The chat shows only that short message.
- **The brief:** the server sees the project's `template_id` and adds the full design brief (`templateBrief`) to the first build's context in `src/server/agent/runner.ts`. It is looked up by id on the server, so a request can't inject its own brief.
- **No questions first:** a template project skips the plan-first questions (`shouldPlanFirst`), because the template already says what to build. Colours are in the brief instead of the palette question.
- **Cost:** a template build is one build call with the brief in the context (roughly 2 to 3 KB of extra input), and saves the planning call.

## Open items
- **"Unlockable":** the brief asked for an *unlockable* section. Nothing is gated; every template is open to anyone who can send a prompt. Gating (for example behind verified credits) touches the credits code, so it is left to the owner to decide. See OPEN_QUESTIONS.
- The thumbnails are renders of the design spec, not of an AI build. The AI build follows the same spec closely but is not pixel-identical; it also writes real, working code.
- Seeding the actual template files into the first build (instead of a brief) would make the result match the thumbnail exactly. It needs a change to the agent's file setup, so it is a follow-up.
